# Seven Segment Display

A small interactive seven-segment display dashboard built with **TypeScript, React, HTML, and CSS**.

The project lets users visualize how a seven-segment display works by:

- Cycling through values from 0–127 in animation mode
- Displaying digits 0–9 in counter mode
- Manually turning the seven segments (`a–g`) on or off
- Showing the active segment pattern as a binary bitstream
- Viewing the decimal value and truth table for digits 0–9

**Live project:** [7 Segment Display](https://7segmentdisplay.vercel.app)

Built with React, TypeScript, Vite, and Framer Motion.
